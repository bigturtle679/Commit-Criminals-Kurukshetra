# NeuroScope 3D — Frontend

> Hackathon project by **Commit Criminals** — Kurukshetra 2026.
> A research-grade brain imaging homepage built with vanilla HTML / CSS / JS.

## Features
- Glassmorphism floating navbar with scroll-shadow
- Hero section: large headline, brain animation video, halo glow effect
- Motion toggle button (pause/play) with reduced-motion support
- Scroll-reveal animations (IntersectionObserver)
- Workspace dialog — file picker with NIfTI / DICOM validation (UI demo only)
- Research & education disclaimer strip
- Workflow steps section
- Fully responsive (mobile, tablet, desktop, 1600px+)
- Keyboard accessible — skip link, focus-visible rings, Escape to close dialog
- SEO: Open Graph + Twitter card meta tags

## Stack
- HTML5 / Vanilla CSS / Vanilla JS
- Google Fonts — Inter
