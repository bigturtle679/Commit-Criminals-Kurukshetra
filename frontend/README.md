# NeuroScope 3D — Frontend

> Hackathon project: NeuroScope 3D homepage — a research-grade brain imaging interface.

## Stack
- Vanilla HTML / CSS / JavaScript
- Google Fonts (Inter)
- Brain animation: MP4 video asset (not committed to git — too large)

## Getting started
`
python -m http.server 8000
`
Then open http://localhost:8000/frontend/

## Disclaimer
For research and education only. Not intended for clinical diagnosis or medical decision-making.
