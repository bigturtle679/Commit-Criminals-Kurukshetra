# NeuroScope 3D

Open index.html in a modern browser. No build step or installation is required.

For an HTTP preview, run `python -m http.server 4173 --bind 127.0.0.1` in this folder, then visit http://127.0.0.1:4173.

Files: index.html (layout), styles.css (responsive styling), app.js (navigation, animation controls and demo dialog), assets/brain.mp4 (user-supplied video).

The Start Analysis button opens a local file-selection demonstration. No upload, inference, segmentation, medical results, or backend is implemented. The animation is illustrative and is not derived from selected files.
